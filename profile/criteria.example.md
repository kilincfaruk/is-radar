# Kriterler — v3.2 (bu metin skorlama prompt'una olduğu gibi eklenir; kurallarla çelişmesin)

## Çalışma şekli
- Sıralama: full remote (Türkiye) > Ankara hibrit > İzmir / Manisa / Aydın hibrit > kabul edilen şehirde ofis.
- Ofise gitmek istemiyorum; kabul edilen şehirde tam ofis ancak şirket ve rol gerçekten iyiyse olur.
- Başka şehirde hibrit → taşınma, −15. Başka şehirde tamamen ofis → elenir. İstanbul'a gitmem.
- Hibrit tek başına eleme sebebi DEĞİLDİR. Düzeni yazan ilanlar (haftada 2 gün ofis, 2 haftada bir vb.) artı; az ofis günü daha artı.
- Çalışma şekli metinde yoksa uydurma: workplace "unknown".

## Roller
- Core: Business Analyst / İş Analisti, Product Owner, Product Manager, Product Analyst.
- Adjacent: yazılım ürünü için Proje Yöneticisi / Project Manager / Proje Uzmanı, Technical BA, Solution Consultant, Implementation Consultant, Sistem Analisti, Product Support Analyst.
- Bridge: test/QA, raporlama, operasyon analisti, süreç geliştirme. Junior test rolü bile olabilir, AI kullanımı açıksa artı.
- Rol genişliği (BA + proje + test karışımı) ARTI, ceza değil.
- Sektör fark etmez.

## Kıdem
- Kendi tecrübeni yaz (ör. "2.5+ yıl B2B SaaS teknik destek + ürün ekibiyle çalışma").
- Senior/8+ yıl isteyen ilan: −20, "denenir"; eleme değil. Sadece ekip yöneticiliği / head / director rolleri dışarıda.
- Stajyer / yeni mezun ilanları dışarıda; "junior" ilan değil.

## İngilizce
- İngilizce ilan tek başına önemsiz. Yazılı/teknik İngilizce yeter (AI araçlarıyla rahat). Yurt dışı ekip/müşteriyle her gün sözlü İngilizce: −10/−15, yine de denenir.

## Maaş ve çalışma tipi
- Net mi brüt mü konuştuğunu ve alt sınırını yaz (ör. "alt sınır X TL net ≈ Y TL brüt"). İlanda maaş yazıyorsa ve altındaysa −15. Yazmıyorsa tahmin yürütme.
- Yarı zamanlı, freelance: elenir. Sözleşmeli: −5, denenir.
- Başvuru sayısı puanı etkilemez.

## Tercih (bonus)
- B2B SaaS; daha önce çalıştığım alanlar (çağrı merkezi yazılımı, enerji/utility yazılımı) — kendi alanlarını yaz.
- Support'tan BA/PO geçişi: müşteri gereksinimi dokümante etme, Jira triyajı, UAT, SQL raporlama tecrübesi CV'de mevcut; "ürün ekibiyle çalışmış support" profilini adjacent değil, core rollere gerçek aday olarak değerlendir.
- Küçük ürün ekibi, Türkçe konuşan müşteri tabanı, Jira / Figma / SQL beklentisi, ilanda AI/LLM araçlarının kullanımı.

## Elenen
- Saf technical support, çağrı merkezi, saha destek, satış, yazılım geliştirme. Destekten çıkıyorum; "BA" başlıklı ama ticket çözen iş, mismatch.
- Ajans/danışmanlık üzerinden istihdam, 7/24 nöbet veya vardiya (kırmızı bayrak, −10; vardiya eleme değil ama ilk tercih hiç değil).
